# Design system

Quiet luxury with heritage warmth: a jeweller's velvet tray, not a discount banner. Imagery leads, type is calm, gold is used sparingly.

Everything below lives as CSS variables in [`app/globals.css`](app/globals.css) and is exposed to Tailwind through `@theme inline`. Change a value there and the whole site follows.

## Palette

| Token | Value | Use |
| --- | --- | --- |
| `--ivory` | `#FAF6EF` | Page background |
| `--ivory-deep` | `#F2EADB` | Alternate bands, rate strip |
| `--paper` | `#FFFDF8` | Cards, form fields, raised panels |
| `--maroon` | `#5E1224` | Primary: headings, buttons, dark bands |
| `--maroon-soft` | `#7A2236` | Reserved for hover or secondary use |
| `--maroon-deep` | `#3F0A18` | Hero, footer, announcement bar |
| `--gold` | `#B08D3C` | Decorative only: hairlines, ornaments, icons on ivory |
| `--gold-ink` | `#7A5C1A` | Gold-coloured **text** on ivory (5.8:1) |
| `--gold-light` | `#D9BE80` | Gold on maroon: eyebrows, icons, outline buttons (7.3:1) |
| `--gold-pale` | `#EADBB5` | Text selection |
| `--charcoal` | `#2A2523` | Body text |
| `--muted` | `#5B524D` | Secondary text (7:1 on ivory) |
| `--on-dark` / `--on-dark-muted` | `#F3E7D0` / `#D8C9AD` | Text on maroon |
| `--whatsapp` | `#0F7A52` | WhatsApp buttons only (white text 5.3:1) |

Rules:

- Gold is an accent. Never use `--gold` for small text on ivory (it fails AA); use `--gold-ink`.
- No purple gradients, no neon yellow, no emoji icons.
- Maroon bands (trust band, footer, bridal checklist) appear at most once per screen of scroll.

## Type

| Role | Family | Notes |
| --- | --- | --- |
| Display | Cormorant Garamond 500 (italic 500 for pull quotes) | Headings, rates, quotes. A single weight keeps the font payload small |
| Body | DM Sans (variable) | Everything else |
| Gujarati | Noto Serif / Sans Gujarati | Loaded only when Gujarati glyphs render |
| Hindi | Noto Serif / Sans Devanagari | Same |

Scale (utility classes in `globals.css`):

| Class | Size |
| --- | --- |
| `.t-display` | `clamp(2.5rem, 7.2vw, 5.25rem)`, hero only |
| `.t-h1` | `clamp(2.25rem, 5.2vw, 4rem)` |
| `.t-h2` | `clamp(1.9rem, 3.8vw, 2.9rem)` |
| `.t-h3` | `clamp(1.4rem, 2.4vw, 1.75rem)` |
| `.t-lead` | `clamp(1.05rem, 1.6vw, 1.25rem)`, muted |
| `.t-eyebrow` | 0.75rem, 600, uppercase, 0.24em tracking, `--gold-ink` |
| body | 1rem / 1.65 |

Indic scripts: root size is scaled to 106.25%, line-height raised to 1.8, and letter-spacing and uppercase are switched off (tracking breaks conjuncts).

## Spacing and layout

- Mobile first, designed at 390px, scaled up.
- `.container-x`: max 80rem, side padding 1.25rem, then 2rem at 640px and 3rem at 1280px.
- `.section-y`: `clamp(4rem, 9vw, 8rem)` vertical rhythm.
- Tap targets are at least 44px (`min-h-11`, `.btn` is 48px, chips are 44px).
- Radius is 2px: crisp, like a hallmark stamp. Only chips and round icon buttons are fully rounded.

## Components

- **Buttons** (`.btn-*`): `primary` (maroon), `gold` (on dark), `outline`, `outline-light` (on dark), `whatsapp`. Uppercase, 0.14em tracking.
- **Link arrow** (`.link-arrow`): text link with a gold underline that widens its gap on hover.
- **Gold rule** (`.gold-rule`): 1px gold hairline with a slow shimmer. `.gold-rule-short` and `.ornament` (a rotated square) are the small versions.
- **Pattern textures** (`.pattern-jali`, `.pattern-paisley`): inline-SVG line patterns at 6 to 10% opacity behind sections. Add the class and, optionally, set `--pattern-opacity`.
- **Image frame** (`.zoom-frame`): clips the image and zooms it 6% on hover (pointer devices only, never with reduced motion).
- **Chips** (`.chip`): filter toggles; the pressed state is solid maroon.
- **Confirm marks** (`.confirm-mark`): small yellow tags that flag `[CONFIRM WITH CLIENT]` text. Set `NEXT_PUBLIC_SHOW_CONFIRM=0` to hide them.

## Motion

- Hero: staggered fade-up of copy, gentle parallax on the image (18% of scroll).
- Sections: scroll-linked fade-up (`.reveal`) where `animation-timeline: view()` is supported; plain content elsewhere.
- Gold accents: shimmer on the hero eyebrow and on hairlines.
- `prefers-reduced-motion: reduce` turns all of it off, including parallax and smooth scrolling.

## Imagery

Photography is the hero, so slots are large and generous. Until the client's photos arrive, every slot holds an SVG placeholder (a line-drawn jewellery motif on a velvet gradient with a faint jali pattern), generated by `scripts/generate-images.mjs`. Each is labelled "Placeholder image" in small type so nobody mistakes it for final art. See [`public/images/README.md`](public/images/README.md).

Photo direction for the real shoot: dark velvet or ivory silk, one light source from the upper left, no props, no hands, jewellery filling about 60% of the frame, 4:5 portrait for products.

## Accessibility

- WCAG AA contrast throughout; `--gold-ink` and `--gold-light` exist for this reason.
- Visible focus ring on every interactive element (maroon on light, gold on dark).
- Skip link, semantic landmarks, one `h1` per page, breadcrumb navigation.
- Carousel: region with `aria-roledescription`, labelled prev/next buttons, Left/Right keys, native scroll-snap.
- Filters are real buttons with `aria-pressed`, grouped in fieldsets; the result count is a polite live region.
- Zoom uses a native `<dialog>` (focus trap, Esc to close, focus returns to the trigger).
- `<html lang>` follows the chosen language.
